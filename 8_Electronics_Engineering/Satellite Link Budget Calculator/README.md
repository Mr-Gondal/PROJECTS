# Satellite Link Budget Calculator

Status: **Planned rebuild**

## Purpose

Build an RF link budget calculator that connects my Space Science background with electrical and communications engineering. This should be one of the most important projects in the portfolio because it fits my education and shows practical engineering calculations.

## Engineering Skills To Show

- Effective isotropic radiated power
- Free-space path loss
- Antenna gain
- Received power
- Noise floor
- Signal-to-noise ratio
- Link margin
- LEO, MEO, and GEO distance awareness

## First Version Scope

Minimum features:

- Input frequency, distance, transmitter power, antenna gains, bandwidth, and receiver noise figure
- Calculate EIRP
- Calculate free-space path loss
- Calculate received power
- Calculate noise floor and SNR
- Show link margin as pass/fail
- Include at least one LEO preset

## Evidence To Capture

- Screenshot of one complete link budget
- Table of inputs and outputs
- Explanation of each formula
- Note about assumptions and limitations

## Entry-Level Job Value

This project supports RF, satellite communications, ground station support, and space technology roles. It shows a clear bridge from Space Science to electrical engineering.
