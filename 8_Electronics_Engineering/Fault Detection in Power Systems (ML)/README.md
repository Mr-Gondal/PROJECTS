# Fault Detection in Power Systems

Status: **Planned rebuild**

## Purpose

Build an entry-level power systems project that demonstrates three-phase fault behavior and basic protection logic. The first version should focus on engineering rules and visualization before adding machine learning.

## Engineering Skills To Show

- Three-phase voltage and current waveforms
- Line-to-ground fault
- Line-to-line fault
- Double line-to-ground fault
- Three-phase fault
- RMS values
- Symmetrical components
- Basic relay trip logic

## First Version Scope

Minimum features:

- Generate balanced three-phase waveforms
- Select a fault type
- Show how voltage and current values change
- Calculate simple RMS values
- Show relay status using threshold rules
- Explain what the fault means electrically

## Evidence To Capture

- Screenshot of normal waveform
- Screenshot of one fault condition
- Table of relay trip thresholds
- Short explanation of symmetrical components

## Entry-Level Job Value

This project supports power systems trainee, electrical maintenance support, and protection systems learning roles. It shows that I understand basic fault behavior and can explain it clearly.
