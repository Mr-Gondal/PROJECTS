# Signal Processing Analyzer

Status: **Planned rebuild**

## Purpose

Build a signal processing tool that shows how noisy electrical or sensor signals can be analyzed in time and frequency domains. This project supports electronics, instrumentation, RF, IoT, and embedded systems learning.

## Engineering Skills To Show

- Time-domain signal visualization
- Frequency-domain analysis using FFT
- Sampling rate and aliasing awareness
- Low-pass, high-pass, and band-pass filtering
- Signal-to-noise ratio
- Total harmonic distortion
- Practical interpretation of noisy sensor data

## First Version Scope

Minimum features:

- Generate a sine wave with adjustable frequency and amplitude
- Add adjustable noise
- Plot the time-domain signal
- Plot the FFT frequency spectrum
- Apply one low-pass filter
- Show before/after signal comparison

## Evidence To Capture

- Screenshot of clean signal vs noisy signal
- Screenshot of FFT peak detection
- Filtered signal example
- Short explanation of what changed after filtering

## Entry-Level Job Value

This project supports instrumentation, embedded sensing, communications, and data acquisition roles. It shows that I can work with signals, not just static data.
