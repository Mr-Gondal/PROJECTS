## Purpose

Build a communications engineering visualizer for basic analog and digital modulation concepts. This project should connect signal processing with RF and satellite communications.

## Engineering Skills To Show

- Carrier signals
- AM and FM basics
- BPSK, QPSK, and 16-QAM
- IQ representation
- Constellation diagrams
- Noise effect using AWGN
- Bit error rate concept

## First Version Scope

Minimum features:

- Select a modulation type
- Generate a simple waveform
- Show a constellation diagram for digital schemes
- Add adjustable noise level
- Explain how noise affects symbol decisions

## Evidence To Capture

- Screenshot of QPSK constellation with noise
