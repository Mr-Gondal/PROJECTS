Key Embedded Concepts
GPIO & Digital I/O
General Purpose I/O pins control LEDs, read buttons, and interface sensors. pinMode() configures direction; digitalWrite()/digitalRead() operate it.
pinMode(LED_PIN, OUTPUT);
digitalWrite(LED_PIN, HIGH);
int btn = digitalRead(BTN_PIN);
PWM Output
Pulse Width Modulation simulates analog output by rapidly switching a digital pin. Duty cycle (0–255) controls average voltage — used for motor speed and LED brightness.
// 0=off, 128=half, 255=full
analogWrite(MOTOR_PIN, 128);
// freq ≈ 490 Hz (D9/D10)
ADC — Analog Read
10-bit ADC converts 0–5V analog signals to 0–1023 integers. Used for potentiometers, temperature sensors, and any variable voltage source.
int raw = analogRead(A0);
float volt = raw * (5.0/1023);
float temp = (volt-0.5)*100;
I2C Protocol
Two-wire serial bus (SDA + SCL) connecting multiple devices. LCD displays, OLED screens, and sensors like BME280 use I2C. Master/slave with 7-bit addresses.
#include <Wire.h>
Wire.begin();
Wire.beginTransmission(0x27);
Wire.write(data);
Wire.endTransmission();
UART / Serial
Universal Asynchronous Receiver/Transmitter enables serial communication. Used for GPS NMEA sentences, debugging via Serial Monitor, and Bluetooth modules.
Serial.begin(9600);
Serial.print("Temp: ");
Serial.println(temperature);
// GPS: SoftwareSerial
Interrupts (ISR)
Hardware interrupts pause the main loop to handle urgent events like button presses instantly, without polling. attachInterrupt() registers a handler function.
attachInterrupt(
digitalPinToInterrupt(2),
buttonISR,
FALLING
);
void buttonISR() { pressed=true; }
